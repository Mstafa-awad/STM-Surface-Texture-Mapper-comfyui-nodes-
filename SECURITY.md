# Security Policy

## Supported versions

The latest published version on the repository's default branch is the supported version.

## Reporting a security issue

Do not post sensitive exploit details in a public GitHub issue.

Use GitHub's private security reporting feature for the repository when available. If private reporting is not enabled, open a minimal issue without disclosing credentials, model access tokens, private files, or a working exploit.

## Model files

STM does not ship model weights. Download model files from the official upstream sources listed in the README and verify that you are using the intended model family before commercial deployment.
